## ما بقي قبل اعتماد المرحلة 0

1. اعتماد أو تعديل قرارات SPEC §10.
2. مراجعة كل حالة اختبار، وتحويل `review` إلى `approved`.
3. مقابلة النصوص الشرعية بمصادرها، وتحويل `verified` إلى `true`.
4. إدخال صيغ U+FD40–FD4F يدويًا في `presentationManual` بعد مراجعة جدول يونيكود. الجدول المولَّد يسردها في `presentationSearchPending`.
5. رفع عدد الحالات إلى الحد الأدنى المطلوب في الوثيقة (300 / 100 / 150 / 200 / 200).
