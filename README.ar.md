# نَصّ · nass

**تطبيع النص العربي والبحث فيه بلا اعتبار للحركات، للقرآن والحديث وكتب التراث، مع مواضع التطابق في النص الأصلي المشكول.** مواصفة واحدة، وثلاث حزم متطابقة: Dart و TypeScript و PHP.

[English](README.md) · [المواصفة](spec/SPEC.md) · [ملفات الاختبار (CC0)](spec/vectors) · [مصادر النصوص ودقة الإسناد](docs/corpus.md) · [تجربة حيّة](https://samt-qa.github.io/nass/)

```text
ابحث عن  «الاعمال»
في       إِنَّمَا الْأَعْمَالُ بِالنِّيَّاتِ
النتيجة  إِنَّمَا <mark>الْأَعْمَالُ</mark> بِالنِّيَّاتِ   (من 9 إلى 21 في الأصل)
```

## لماذا

البحث في النص المشكول يبدو سهلًا. تحذف الحركات فتجد الكلمة، لكنك تفقد موضعها في النص الذي يقرؤه المستخدم. ثم تأتي علامات الضبط القرآني، وصيغ العرض مثل «ﷲ» و«ﻻ»، ورموز الصلاة مثل «ﷺ»، وعلامات الاتجاه الخفية، والحروف الفارسية الشبيهة، وكل منها يُفسد البحث بطريقته. وأغلب المكتبات تعالج بعضها، بلغة واحدة، بلا اختبارات مشتركة.

**نَصّ** يختلف في ثلاثة أمور:

1. **المواضع في الأصل.** كل محرف مطبّع يُعرف مصدره، فتُظلِّل النص المشكول الذي يراه القارئ.
2. **مواصفة واحدة، ثلاث لغات، مخرجات متطابقة بايتًا ببايت.** الحزم الثلاث تجتاز 952 حالة اختبار مشتركة، ومعها اختبار تفاضلي مع نسخة مستقلة: صفر اختلاف في 172,463 مقارنة على الكتب الستة.
3. **مصمَّم للنص الشرعي.** يفهم صيغ الترضّي («ﷺ»، «رضي الله عنه»، «عز وجل» بعد لفظ الجلالة فقط)، وفيه مفتاح لأسماء الرواة `nameKey`، وتقسيم تجريبي للإسناد والمتن مقيس على أحاديث موسومة باليد من الكتب الستة.

## الحزم

| اللغة | الحزمة | التثبيت | التوثيق |
|---|---|---|---|
| Dart / Flutter | `nass` | `dart pub add nass` | [packages/dart](packages/dart) |
| TypeScript / JS | `@samt/nass` | `npm i @samt/nass` | [packages/js](packages/js) |
| PHP 8.3 فأحدث | `samt/nass` | `composer require samt/nass` | [packages/php](packages/php) |

> **الحالة: 0.1.0، لم تُنشر بعد.** الكود مكتمل ومختبَر، والنشر على pub.dev و npm و Packagist يحتاج حسابات المشرفين. حالات الاختبار `review: pending` حتى يراجعها مختص.

## أمثلة

```ts
import { normalize, findAll, highlight, nameKey } from "@samt/nass";
import { splitIsnad } from "@samt/nass/isnad"; // تجريبي، في مدخل منفصل

normalize("إِنَّمَا الْأَعْمَالُ بِالنِّيَّاتِ");            // "انما الاعمال بالنيات"
findAll("إِنَّمَا الْأَعْمَالُ بِالنِّيَّاتِ", "الاعمال");   // [{ start: 9, end: 21, text: "الْأَعْمَالُ" }]
highlight(text, "الاعمال", { wholeWord: true });
nameKey("أبي عبدِ الله البخاريّ رحمه الله");               // "ابو عبدالله البخاري"
```

## مستويات التطبيع

| المستوى | الاستعمال | ماذا يفعل |
|---|---|---|
| `clean` | التخزين والعرض | يحذف التطويل والمحارف الخفية، ويفك صيغ العرض (عدا رموز الصلاة)، ويوحّد المسافات، ويركّب الهمزة والمدة. **شكل النص لا يتغير.** |
| `search` (الافتراضي) | البحث والفهرسة | ما سبق، ويفك «ﷺ» و«﷽»، ويحذف الحركات وعلامات الضبط القرآني، ويوحّد صور الألف والياء والكاف والهاء، ويحوّل الأرقام العربية والفارسية، ويجعل الترقيم مسافة، ويصغّر اللاتينية. ومع `honorifics: strip` يحذف صيغ الترضّي المكتوبة. |
| `loose` | البحث المتسامح | ما سبق، و«ة» ← «ه»، و«ؤ» ← «و»، و«ئ» ← «ي»، ويحذف «ء» المنفردة. يدمج بعض الكلمات المختلفة عمدًا. |

كل قاعدة بسببها ومجالاتها في [spec/SPEC.md](spec/SPEC.md).

## تقسيم الإسناد والمتن (تجريبي)

على 100 حديث محجوز من الكتب الستة، يصيب الحدّ بين الإسناد والمتن في **91%** منها، و98% في حالات التصميم المئة. النتائج لكل كتاب وتحليل الأخطاء في [docs/corpus.md](docs/corpus.md). هو محلل تقريبي لا عالم بالرجال، و`narrators` لا يحدد هوية الراوي.

**تنبيه:** تطابق `nameKey` لاسمين لا يعني أنهما لشخص واحد.
